The objective was to build an interactive Finance Analytics Dashboard that helps stakeholders monitor financial performance, understand customer behavior, and analyze transaction trends.

Tools & Technologies Used
1. SQL – Data Analysis*
- Queried and analyzed financial transaction data.
- Used filtering, aggregations, and grouping to extract meaningful insights.
- Prepared data for further analysis.

2. Microsoft Excel – Data Cleaning & Preparation*
- Performed data cleaning and validation.
- Organized and prepared datasets for analysis.
- Used Excel for preliminary data exploration.

3. Power BI – Data Visualization & Dashboard Development*
- Created interactive dashboards and KPI cards.
- Developed DAX measures for financial metrics and YoY comparisons.
- Built dynamic filters and interactive visualizations.
- Implemented detailed transaction-level views and drill-down analysis.

Business Questions Addressed
- Which customer segments contribute the most to transaction value?
- Which states have the highest financial performance?
- How are transaction amounts changing month over month?
- What percentage of transactions are successful?
- Which transaction types generate the highest fees and taxes?
- How has financial performance changed year over year?
- How can stakeholders investigate individual transactions?
